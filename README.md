# Grimpeurs de Pen-Hir

Site de l'association Les Grimpeurs de Pen-Hir, qui anime le mur d'escalade communal de Camaret-sur-Mer.

## Développement local

Le site est statique. Ouvrir `index.html` dans un navigateur ou lancer un serveur HTTP local dans ce dossier.

## Déploiement

Le dépôt est prêt pour Netlify. Le fichier `netlify.toml` publie directement la racine du projet, sans commande de compilation.

## Contenus à maintenir

- horaires et parcours d'inscription dans `index.html` ;
- photographies dans `assets/photos/` ;
- provenance des illustrations et photographies dans `assets/README.md`.
